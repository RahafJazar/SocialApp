Togetherly (SocialApp)

A social media front-end app built with Angular, featuring authentication screens and multi-language support.

🔗 Live demo: https://social-app-ven9.vercel.app

About

Togetherly is a front-end project that simulates a social media experience.

Note: This project has no custom backend. It connects to a public third-party API on the internet, so the focus here is on the front-end.
